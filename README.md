# Instafake

Локальная галерея изображений в духе Instagram: профили с аватарами и описанием,
галереи в каждом профиле, фотографии с подписями, лайки и комментарии от
фейковых комментаторов. Без регистрации и без сервера — всё живёт в браузере.

## Запуск

Готовые лаунчеры сами проверяют Node.js и ставят зависимости при первом запуске:

- **Windows** — двойной клик по `start.bat` или `start.bat` в cmd/PowerShell.
- **Linux** — `./start.sh` (если нет права на запуск: `bash start.sh`).

Оба открывают приложение в браузере на `http://127.0.0.1:5173`. Чтобы запустить без
открытия браузера: `NO_OPEN=1 ./start.sh` или `set NO_OPEN=1 && start.bat`.

Вручную:

```bash
npm install
npm run dev        # http://127.0.0.1:5173
```

Сборка: `npm run build`, локальный просмотр сборки: `npm run preview`.

## Что внутри

- **Профили** — имя пользователя, имя, описание и фото профиля (необязательно).
- **Галереи** — подборки фотографий на странице профиля, с обложкой из последнего кадра.
- **Фотографии** — загрузка с компьютера (можно несколько сразу), описание можно
  добавить при загрузке и отредактировать позже на странице публикации.
- **Комментарии** — в комментатора можно выбрать любого из 16 демонстрационных
  аккаунтов, профиль пользователя или создать нового прямо в списке.
- **Лента** — все публикации, лайки (в том числе двойным кликом по фото),
  сохранения и подписки.

Демонстрационные профили, 12 фотографий, 4 галереи и 16 комментаторов создаются
при первом запуске. Демо-фотографии лежат в `public/samples`, при сидировании
они копируются в IndexedDB.

## Хранение данных

Фотографии, аватары и метаданные хранятся в IndexedDB (`instafake-gallery`) и не
покидают устройство. Никакие файлы не загружаются в сеть. Загруженные фото
уменьшаются до 1800 px по длинной стороне и сохраняются в WebP; аватары — до 480 px.

Чтобы сбросить всё и снова увидеть демо-данные: DevTools → Application → IndexedDB →
удалить базу `instafake-gallery` и обновить страницу.

## Стек

React 19, TypeScript, Vite. Никаких UI-библиотек: собственная CSS-дизайн-система
описана в `DESIGN.md`. Маршрутизация — hash-роутер без зависимостей.
